# Git & GitHub Übungsprojekt

## Kurzbeschreibung
Dieses Repository dient als praktisches Übungsprojekt für die Versionskontrolle mit Git und die Synchronisation mit GitHub über das WSL-Terminal in VS Code.

## Inhalt des Repositories
* `README.md` – Projektdokumentation und Übersicht über das Repository.
* `.gitignore` – Konfigurationsdatei zum Ausschließen temporärer oder sensibler Dateien.
* `notizen.txt` – Einfache Textdatei für erste Arbeitsnotizen und Tests.

## Erste Nutzung und Zweck
Das Projekt wird genutzt, um grundlegende Git-Workflows (`init`, `add`, `commit`, `push` und `pull`) sicher anzuwenden und lokale Änderungen strukturiert auf GitHub zu sichern.
Änderung aus dem ersten lokalen Repository.
